# Trang List combo (bản HTML duyệt)

- `index.html` — trang ghép đầy đủ.
- `components/` — từng component (HTML xem trước + CSS riêng), mở `components/index.html` để xem danh sách.
- `images/` — ảnh của trang (lấy từ assets/images gốc, đã nén WebP).
- Font + base.css dùng chung ở `../shared/`.
